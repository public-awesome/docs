# Marketplace

Marketplace is a onchain orderbook for NFT asks and bids. Stargaze Marketplace allows creators to request for a denom change, where their collections can be listed in different tokens.\
Feature rich and easy to use, the Marketplace allows trait, price, rarity filters and sorting. It also has a complete analytics page with all the relevant data for an NFT project.\
\
**Current fee structure**:\
\
2% for collections denominated in STARS\
3% for collections denominated in other tokens\
\+ Royalties, defined by each collection creator

\
The fees are paid by the seller. For a fee reduction,  there is the [Superstars program](../../tokenomics/superstars-program.md), where staking STARS give up to 50% discount in fees.
